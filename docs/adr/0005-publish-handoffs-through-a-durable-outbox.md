# Publish handoffs through a durable outbox

Musement records each explicit downstream selection as a versioned JSON Handoff Event in a durable local outbox, exposed first through the CLI and later through HTTP or webhook adapters. Publication is at least once: events have globally unique IDs and ordered stream positions, while each consumer maintains an independent checkpoint and deduplicates retries by event ID. The MVP retains events without automatic expiration. Directly launching downstream agents, globally removing an event after one consumer reads it, or coupling consumers to Musement's database would make selection responsible for pipeline execution and internal storage stability; the outbox instead provides reliable, consumer-driven publication without requiring a message broker or pretending to guarantee exactly-once processing.

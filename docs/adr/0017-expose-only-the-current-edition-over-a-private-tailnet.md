# Expose only the current edition over a private tailnet

Musement may publish the standalone Edition Review at a stable private HTTPS URL for devices in the user's Tailscale network. The browser surface always resolves to the current canonical Daily Edition and exposes no dated archive, backlog, unread state, or completion state. Failure to publish or reach the page does not change the edition and creates no debt.

The implementation separates three modules. The platform-neutral private-site module atomically publishes one HTML document and serves only `/today` on loopback with `no-store` and restrictive security headers. The Tailscale adapter discovers the current user's online node DNS name and owns only the `/musement/today` Serve route. A macOS lifecycle adapter keeps the loopback server available through a user LaunchAgent; other platforms may run the same server command under their native service manager. Email delivery knows only the optional private HTTPS URL and never imports Tailscale or platform lifecycle details.

This design keeps account names, node names, tailnet domains, filesystem roots, and localhost ports out of product code. It also avoids a hosted Musement account or public web application. Access depends on Tailscale connectivity and the tailnet's access rules; the origin binds only to `127.0.0.1`, so tailnet identity headers cannot be spoofed remotely by bypassing Tailscale. Enabling Tailscale HTTPS may publish the node and tailnet DNS names in certificate-transparency logs, which requires the tailnet owner's explicit one-time consent.

# Persist derived video transcripts

Musement persists a video's transcript indefinitely, keyed by video id, as derived metadata rather than as cached source content. A YouTube feed carries only a promo description, which usually falls below the coded substance floor and cannot be judged on its own; the transcript is what makes a video a real candidate. Transcripts are immutable once published, so a resolved transcript is fetched once and reused forever. This sits with the derived summaries, fingerprints, and Selection Traces that Musement already keeps in operational state, and it does not extend the temporary Raw Material Cache (ADR 0011), whose fetched source text still expires.

A caption-less video records that fact with its real duration and is re-checked after fourteen days, because captions can be added later. Transcript retrieval uses YouTube's undocumented internal player endpoint through the iOS client identity; there is no official alternative, since the Data API serves captions only for videos the caller owns. Every retrieval failure degrades to the feed description rather than blocking the edition, and only the video's own captions are stored, so this remains derived metadata and not a media archive.
